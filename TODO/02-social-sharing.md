# ТЗ-02. Кнопки шеринга на странице статьи

**Статус:** черновик для согласования
**Приоритет:** высокий
**Связанные ТЗ:** ТЗ-04 (счётчики), ТЗ-10 (OG-теги / SSR / мета)

---

## 1. Цель

Трафик из соцсетей — основной канал донора (трендовый контент «инвестиционно.рф» распространяется через Telegram/VK/Dzen). Сейчас у пользователя нет способа поделиться конкретной статьёй в один клик — только ручным копированием URL из адресной строки. Задача: добавить блок шеринга внутрь страницы статьи, чтобы снизить трение при репосте и замерить, откуда приходит трафик (UTM).

## 2. Текущее состояние

- Страница статьи: `apps/web/src/pages/ArticlePage.tsx`. В разметке **нет** никаких кнопок шеринга.
  - Заголовок + кнопки избранного/подписки — строки 99–108 (`<div className="flex items-start justify-between…">`).
  - Тезис идеи — строки 111–115.
  - Тело статьи (`dangerouslySetInnerHTML`) — строки 138–141.
  - Блок «Источник» — строки 150–157. После него идут карусели (строки 159–167).
- Каналы проекта уже заданы в футере `apps/web/src/components/Layout.tsx:103–106`: Telegram `https://t.me/insidetraderu`, VK `https://vk.com/inside_trade`, YouTube `https://youtube.com/@insidetraderu`, Dzen `https://dzen.ru/id/5b5ee9d51a66a400a9961a66`.
- `<head>`: `apps/web/index.html:6` — статичный `<title>Инвестиционно.рф — Инвестиционно про будущее</title>`, единственный description. **OG-тегов (`og:title`, `og:description`, `og:image`) нет вообще**, клиентского управления `document.title` тоже нет (проверено grep по `apps/web/src` — совпадений нет).
- SPA: react-router (`useParams` в `ArticlePage.tsx:1`), URL статьи имеет вид `/{type}/{slug}` (роут `/trend/…`, `/kompaniya/…` — в футере Layout; страницы статей подтверждены в `ArticlePage.tsx:68–72`).

## 3. Требования

### 3.1 Размещение

Блок шеринга показывается **на всех типах статей** (`analitika`, `novost`, `ideya`, `interesnoe`, `video` — см. `TYPE_LABELS` в `apps/web/src/components/ArticleCard.tsx`) в двух точках страницы:

1. **Под заголовком** — сразу после блока тезиса/чипов (`ArticlePage.tsx:117–119`, `<EntityChips>`), до тела статьи. Позиция: в строке с метаданными или отдельной строкой ниже неё.
2. **В «футере» статьи** — после блока «Источник» (`ArticlePage.tsx:150–157`) и перед нижними каруселями (строка 159). Пользователь, дочитавший статью, — самый тёплый для репоста.
3. **Sticky-панель сбоку на десктопе** — опционально (см. 3.5, решается на реализации).

Обе точки (1) и (2) — обязательны, рендерятся одним и тем же компонентом.

### 3.2 Каналы

Обязательные:

- **Telegram** — `https://t.me/share/url?url={ENCODED_URL}&text={ENCODED_TEXT}`
- **VK** — `https://vk.com/share.php?url={ENCODED_URL}&title={ENCODED_TEXT}`
- **Копия ссылки в буфер** — Clipboard API (`navigator.clipboard.writeText`) с визуальным фидбеком («Ссылка скопирована», автоскрытие 2–3 с)
- **Нативный шер** — `navigator.share` (Web Share API): **primary на мобильных**, на десктопе скрыт (или показан только при наличии `navigator.share`). Внутри нативного шера передаётся `url` с UTM (см. 3.4).

Обсуждаемые (включить по решению заказчика):

- **WhatsApp** — `https://wa.me/?text={TEXT}%20{URL}` (целевая аудитория РФ; мессенджер активно используется). Рекомендация: включить.
- Одноклассники / Dzen-шеринг — **не делаем**, Dzen не имеет публичного endpoint шаринга.

### 3.3 Реализация (без сторонних SDK)

- Никаких JS-SDK соцсетей (VK Open API, Telegram widget js). Только готовые URL + `window.open(url, '_blank', 'popup,width=…,height=…')`.
- Попап: `noopener,noreferrer` (передать `rel` не получится у `window.open` — вместо этого после `open()` делать `win.opener = null`), размеры ~ 600×600 для Telegram/VK. **Fallback:** если `window.open` вернул `null` (popup blocker) — обычный `window.location.href = url` (для VK/Telegram открытие в той же вкладке допустимо) либо временная `<a>` с `target="_blank"`.
- Для `video`-статей (`ArticlePage.tsx:125–136`) текст шеринга — `article.title`, URL — страница статьи (не embed).
- Clipboard API доступен только в secure context; fallback — устаревший `document.execCommand('copy')` через временный `<textarea>` (сайт должен работать по HTTPS; если есть dev по HTTP — фидбек «Скопируйте вручную» + `prompt`). Покрыть обе ветки.

### 3.4 UTM-метки

Во все шаринг-URL добавляются метки:

```
utm_source={site|telegram|vk|whatsapp|native_share}
utm_medium=share
utm_campaign=article_share
utm_content={type}  # analitika | novost | ideya | interesnoe | video
```

- `utm_source` = соцсеть, в которую шарим (на своём сайте метки ничему не мешают — они уходят во внешний сервис и возвращаются в аналитику при переходе обратно).
- URL для копирования в буфер — **без UTM** (чистая ссылка «для человека»), либо с UTM — решить на созвоне; рекомендация: буфер без UTM.
- Итоговый URL собирать через `URLSearchParams`, не конкатенацией строк.

### 3.5 Sticky-панель (опционально)

На десктопе (≥ `lg`, 1024px — общий контейнер в `Layout.tsx:19` `max-w-5xl`, колонка статьи `max-w-3xl` в `ArticlePage.tsx:89`) вертикальная колонка иконок `position: fixed`/`sticky` слева от текста. На мобильных — не показывать, только инлайн-блоки. Если верстается сложно — отложить отдельным ТЗ, не блокировать основную поставку.

### 3.6 Подсчёт шеров

**Не входит.** Отложить в ТЗ-04 «Счётчики»: бэкенд-эндпоинт + инкремент по клику + отображение счётчика на карточках (`ArticleCard`, `NewsCard`, `VideoCard`, `IdeaCard`) и рядом с кнопками. В ТЗ-02 только событие клика в аналитику (см. приёмку).

### 3.7 OG-теги (зависимость, не входит в объём)

Сейчас OG-тегов нет (`apps/web/index.html:3–8` — только `<title>` и `<meta name="description">`), а SPA отдаёт пустой `<div id="root">`. Скроллеры соцсетей при репосте возьмут `og:title`/`og:description` из `<title>`/description главной страницы — **одинаково для всех статей**, без картинки. Это фиксируется как внешняя зависимость:

> **Зависимость от ТЗ-10 «OG-теги / пререндер»:** без SSR/пререндера или сервиса (например, prerender.io / самописного edge-рендера) превью репоста будет некорректным. Кнопки из ТЗ-02 работают и без ТЗ-10, но эффективность шеринга ограничена. ТЗ-10 — отдельная задача, блокирует только качество превью, не блокирует поставку кнопок.

Дополнительно в ТЗ-10: клиентская установка `document.title = article.title` на странице статьи (однострочный фикс, можно сделать сразу в рамках ТЗ-02 — см. 4.4).

### 3.8 Дизайн

В фирменной палитре (чёрный `#000`, лайм `#beff00` / `#c9ff2a`, границы `#2a2a2a`, текст `zinc-500/400`, паттерны из `Layout.tsx` и `ArticlePage.tsx`):

- Иконки: inline SVG (как принято в проекте — см. иконку поиска `Layout.tsx:26–28`), моноширинный набор Telegram/VK/WhatsApp/link, без эмодзи и внешних картинок.
- Кнопка — `rounded-full` или `rounded-lg`, `border border-[#2a2a2a]`, иконка `text-zinc-400`, hover: `text-[#beff00]` + `border-[#beff00]/40` (паттерн hover-ссылок в футере `Layout.tsx:63` `hover:text-[#c9ff2a]`).
- Primary-кнопка «Поделиться» (нативный шер на мобильных): `bg-[#beff00] text-zinc-950`, как «Войти» (`Layout.tsx:39`) — визуальный акцент на главном действии.
- Фидбек копирования: тултип/подпись «Ссылка скопирована» лаймом, `transition-opacity`, автоскрытие ~2.5 c. Никаких `alert()`.

## 4. Реализация (файлы : компоненты)

### 4.1 Новый файл `apps/web/src/components/ShareButtons.tsx`

- Обработчики: `openSharePopup(url)` (popup + fallback), `copyLink()` (Clipboard API + fallback + фидбек через `useState`).

## 5. Критерии приёмки

1. На странице любой статьи (`/analitika/…`, `/novost/…`, `/ideya/…`, `/interesnoe/…`, `/video/…`) блок шеринга виден в двух местах: под заголовком/чипами и после «Источника»/текста статьи.
2. Клик по **Telegram** открывает `https://t.me/share/url?url=…&text=…` в попапе ~600×600 (или новой вкладке при заблокированном попапе); в переданном URL присутствуют `utm_source=telegram&utm_medium=share&utm_content={type}`.
3. Клик по **VK** аналогично через `https://vk.com/share.php?url=…&title=…` с UTM `utm_source=vk`.
4. **«Копировать ссылку»** кладёт URL в буфер (Clipboard API; подтверждено в Chrome/HTTPS), показывает фидбек «Ссылка скопирована» с автоскрытием; при недоступности API — fallback `execCommand` либо понятное сообщение об ошибке.
5. На мобильном (Android Chrome, iOS Safari) основная кнопка «Поделиться…» вызывает нативный шит `navigator.share` с заголовком и URL; на десктопе без `navigator.share` кнопка не рендерится или деградирует в «Копировать ссылку» — поведение зафиксировано в ТЗ и одинаково на всех статьях.
6. Popup blocker: при блокировке всплывающего окна шаринг не «проваливается молча» — пользователь видит результат (новая вкладка/страница шаринга).
7. Все шаринг-URL корректно закодированы (`encodeURIComponent`/`URLSearchParams`): проверить статью с заголовком, содержащим пробелы, кавычки и кириллицу.
8. Видео-статья: шарится страница статьи, а не embed-URL.
9. Клик по любой кнопке шеринга шлёт событие в аналитику (название события `share_click`, параметры: `channel`, `type`, `article_id`) — если аналитика ещё не подключена, оставить `console.debug`-заглушку с TODO на ТЗ-04.
10. Визуал соответствует 3.8: тёмная тема, лайм-ховеры, без внешних ассетов, адаптив от 320px до десктопа, статья на `max-w-3xl` (`ArticlePage.tsx:89`) не «плывёт».
11. `npm run build` в `apps/web` без ошибок; ручной проход по страницам всех 5 типов контента.

## 6. Риски

| Риск | Влияние | Митигация |
|---|---|---|
| Popup blockers режут `window.open` без прямого user gesture | Кнопка «не работает» с точки зрения пользователя | Fallback на `target="_blank"` / `location.href`; проверить в Safari (strictest) |
| Clipboard API требует secure context и может отклонять промис без user gesture | «Скопировать» не работает на HTTP-dev или старых браузерах | Fallback `execCommand`; тест на dev (HTTP) и prod (HTTPS) |
| `navigator.share` есть на десктопе не везде (нет в десктопном Firefox), поведение отличается по платформам | Расхождение UX десктоп/мобайл | Feature-detect `if ('share' in navigator)`; единый fallback «Копировать ссылку» |
| Блокировщики рекламы (uBlock, AdGuard) могут резать URL `vk.com/share.php`/`t.me/share` только если страница сама в фрейме — не наш случай, но фанатские фильтры бывают | Редкий: попап не открывается | Тот же fallback, что и для popup blocker |
| Отсутствие OG-тегов (зависимость от ТЗ-10) | Превью репоста — общий заголовок сайта без картинки; шеринг менее кликабелен | Зафиксировано как внешняя зависимость; не блокирует поставку кнопок |
| SPA: роботы соцсетей при первом проходе не увидят контент статьи | То же, что выше | ТЗ-10 (SSR/prerender/edge) |
| UTM в URL, скопированном «для человека» | «Грязные» ссылки в личной переписке | В 3.4 рекомендовано: буфер без UTM |
| Неопределённость по WhatsApp | Расхождение объёма | Решение заказчика до старта работ |
