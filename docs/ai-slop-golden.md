# Golden set: регрессионная проверка аудита ИИ-штампов

Эталонные ожидания для `scripts/ai-slop-golden.mjs`. Выводы полевого исследования
(субагент, 2026-11-20): прогон аудита по 5 текстам сайта. После каждой правки промпта
`SLOP_SYSTEM` (apps/api/src/routes/aiSlop.ts) перезапустить скрипт и сверить распределение.

## Инварианты (должны держаться при правках промпта)

1. **Порядок групп**: ИИ-тексты (A–C) стабильно ниже человеческих (D2) на 15+ баллов.
2. **C всегда хуже B, B хуже A** — «Прометей» с дублями и кластерами палится сильнее всех.
3. **D — отказ по длине**, а не «100 баллов»: короткие тексты не аудируются (<300 слов).
4. **duplicated_passage на C** ловится детерминированно (не зависит от LLM) — проверять
   в первую очередь: если пропал, сломан не промпт, а `findDuplicateParagraphs`.
5. **B**: замечаний по template_rhythm ≤ 1–2 — жанр «перевод пресс-релиза» защищён
   исключением в промпте; если их 4+ — исключение регрессировало.
