# Админка и производство контента

Документ описывает админ-панель (`apps/admin`, порт 1002 локально / `admin`-домен или `:8443` на VDS) и сквозной процесс создания контента: от сырого текста до опубликованной статьи. Актуально на 2026-11-16.

---

## 1. Сквозной процесс: от текста до публикации

```
сырые заметки/ссылка
   └─► ContentMaster (чат с AI)         — рерайт, фактчек, поиск первоисточника
        └─► черновик (тип, теги, тело)  — правка в один клик
             └─► редактор статьи         — обложка, связи, стадия, SEO, просмотры
                  └─► публикация         — страница на сайте, карусели, sitemap
```

Два пути создания материала:

1. **Через ContentMaster** (основной для новостей и рерайтов) — см. раздел 2.
2. **Напрямую в редакторе** (Статьи → «Новая статья») — для ручных материалов, аналитики, правок.

---

## 2. ContentMaster — AI-редактор (первый пункт меню)

Чат-интерфейс с памятью сессий. Работает на выбранном в «Настройки LLM» провайдере (Kimi или DeepSeek; поиск — на DeepSeek).

### 2.1 Сценарии работы

| Действие | Как |
|---|---|
| Рерайт текста/ссылки | Вставить в «Текст или ссылка», описать задачу → «Отправить». Ссылка выкачивается автоматически |
| Проверка фактов | Кнопка «🔍 Проверить факты» — модель выделяет утверждения, вердикты (✓ подтверждено / ✗ спорно / ? не проверено) + источники. С поиском в интернете — реальные ссылки |
| Поиск первоисточника | Кнопка «🌐 Найти первоисточник» |
| Продолжение диалога | Писать следом: «сделай короче», «добавь цифры», «напиши статью с учётом проверки». Модель помнит последние 8 ходов (фактчек с его вердиктами входит в контекст следующих запросов) |
| Поиск в интернете | Галочка «искать в интернете» — агентный цикл: модель формирует запросы, исполняет DeepSeek Search, отвечает со ссылками |

**Режимы.** «фактчек ⇄» — переключатель рядом с кнопкой отправки. После завершённого фактчека режим сам переключается на «рерайт» (следующий ход пишет текст, а не список утверждений). Загруженные сессии стартуют в режиме «рерайт».

**Сессии** — персистентная история слева (селект). Можно вернуться к вчерашней переписке; контекст подтягивается с сервера.

### 2.2 Панель «Черновик» (под чатом)

Появляется после «взять за основу» у любого ответа:

- **Контент** — TipTap-редактор с телом статьи (правится прямо там; у фактчека без текста кладётся итог проверки; каждый следующий ответ AI подменяет содержимое редактора)
- Заголовок (редактируется), slug (автотранслит), лид, **SEO description**, тезис (для идей), источник, URL видео (для типа «видео»), доступ (открытый/по авторизации/по тарифу), **стартовые лайки/репосты** (seed-докрутка, как просмотры)
- **ИИ-кнопки ✨ на полях** (те же промпты, что в редакторе статьи): заголовок (3 варианта, клик применяет+slug), лид (250±20%), SEO (200±10%), тезис (для идей), обложка (двухэтапно: «✨ Промпт из текста» → «Сгенерировать (Kimi)»; картинка создаётся до сохранения и встаёт на статью при создании черновика). Кнопка **«✨ Заполнить всё»** гоняет всё последовательно одним кликом
- **Связи из текста (AI)** — автоматически после каждого ответа: чипсы трендов и компаний из нашей базы (клик → в теги), пунктирные «+ Название» — компании вне базы (клик → создать и привязать)
- Облака тегов: тренды, компании, тикеры (автодополнение)
- «Создать черновик» → статья в админке со всеми связями → ссылка «Открыть в редакторе». Валидация: без типа/заголовка показывает понятную ошибку; при занятом slug сервер ответит 409 — смените slug в панели

### 2.3 Техника (кратко)

- `POST /api/admin/content-master/rewrite` — ядро; SSE-стриминг ответа; сессии через `sessionId`; поиск — агентный цикл (web_search исполняет платформа: DeepSeek Search / DDG-fallback)
- `POST /api/admin/content-master/extract` — извлечение связей (каталог компаний/трендов в промпте, ~3К токенов)
- Лимиты: rewrite 15/мин; окно контекста 8 ходов × 1500 симв.; source до 15К симв. (обрезка с пометкой `truncated`)

## 3. Редактор статьи (Статьи → карточка)

Поля: тип (новость/событие/идея/аналитика/интересное/видео), заголовок + **«✨ Заголовок»** (3 варианта от AI), slug (авто; при смене ТИПА редактор сразу проверяет, не занят ли slug в новом типе — иначе сохранение упадёт с 409), тезис (идеи), лид + «✨ Сгенерировать из текста», SEO description + «✨ (SEO)», контент (TipTap; тулбар: H2/H3, списки, цитата, ссылка, **картинка 📤 с компьютера / 🗂 из медиатеки / 🖼 по URL**, таблицы, отмена), обложка (загрузка с компьютера / выбор из медиатеки / **двухэтапная генерация**: «✨ Из статьи» пишет фотореалистичный промпт → «Сгенерировать (Kimi)» рисует; при ошибке Kimi промпт остаётся для копирования). Куда попадает обложка на сайте — см. матрицу в разделе 7.

**Счётчики (секция «докрутка», только admin):** стартовые просмотры + автодокрутка (интервал, диапазон), **стартовые лайки и репосты** (seed прибавляется к реальным на карточках и детальной; реальные инкременты идут поверх). Всё — только PATCH, авторы полей не видят.

**Связи:** облака тегов компаний/тикеров/индустрий/трендов (ввод → подсказки, Enter — создать новое).

**Стадия идеи** (для type=ideya): чипсы таймлайна — Идея, Pre-seed…IPO, **Торги на бирже** (включает график тикера на сайте).

**Доступ:** public / auth / по тарифу (выбор тарифа).

**Автосохранение:** раз в минуту при наличии правок (индикатор «Черновик сохранён в HH:MM»). Новая статья автосохраняется **только как черновик**; опубликованная обновляется без смены статуса; уход со страницы с правками — браузерный confirm. Счётчики-докрутки новой статье досылаются вторым запросом сразу после первого сейва.

Кнопки: Сохранить / Опубликовать / Вернуть в черновик / 👁 Превью (устройства).

## 4. Остальные разделы админки

| Раздел | Что делает |
|---|---|
| **ContentMaster** | см. раздел 2 |
| **Статьи** | список, поиск, фильтр по типу (подзакладки: новость/событие/идея/аналитика/интересное), создание/правка/публикация/архив |
| **Сюжеты** | тематические цепочки; состав, порядок серий (↑/↓), главный материал; все-видео сюжет = плейлист на сайте |
| **Компании** | карточки профилей: тикеры, индустрии, раунды, описание (TipTap) |
| **Тренды** | лендинги трендов: лонгрид (TipTap), связанные материалы |
| **Индустрии / Тикеры** | справочники (тикер: символ, компания, биржа) |
| **Медиатека** | загруженные и сгенерированные файлы; выбор для обложек; ✎ переименование (alt), удаление с карточки; **автопережатие**: любая картинка (загрузка до 10 МБ и ИИ-генерация) прогоняется через sharp — до 1600 px по ширине + WebP q80, типичный файл 100–500 КБ вместо многомегабайтного оригинала |
| **Редиректы** | 301/302 для переезда со старого сайта (без перезагрузки, боты учитываются в SSR) |
| **Пользователи** | роли (reader/author/admin/super_admin), тарифы, блокировка (is_blocked — логин и админка откажут), bio |
| **Тарифы** | каталог планов 1:1 с PULSE: цены/период, фичи, «популярный», архивация, подписчики плана; **доступность** — свойство плана (массив продуктов invest/pulse) |
| **Фичи** | реестр фич тарифов (драйвит чекбоксы планов) |
| **Настройки Kimi** | LLM-провайдер (Kimi/DeepSeek), ключи (маскируются), модели (live-списки), baseUrl с allowlist |
| **Метрики** | продуктовые метрики + **скорость страниц** (телеметрия загрузки с сайта) |
| **Аналитика** | просмотры, лайки, шеры |

## 6. Частые вопросы

**«Поставил стартовые просмотры, при переоткрытии нули»** — просмотры сохраняются только для существующей статьи. На новой: сохраните первый раз (создастся), затем поставьте и сохраните снова — либо автодосыл сработает сам.

**«Фактчек возвращает список вместо статьи»** — активен режим «фактчек»; переключите тогл ⇄ на «рерайт» или жмите «✏️ Новость для инвесторов».

**«Картинка для обложки не генерируется»** — генерация рисует через Moonshot/Kimi (ключ `MOONSHOT_API_KEY`); DeepSeek рисовать не умеет. Промпт пишет DeepSeek, этап 2 — Kimi; без ключа Kimi промпт остаётся в поле для копирования.

**«Сайт/админка не обновились после деплоя»** — жёсткое обновление один раз (`Ctrl+Shift+R`); index.html с no-cache, дальше обновления приезжают сами.

**«API 409: Такой slug уже есть у статьи этого типа»** — пара «тип + slug» уникальна. Дубль создаётся автотранслитом из заголовка: либо откройте существующую статью из списка «Статьи», либо поменяйте slug (добавьте `-2`/дату), либо удалите старый черновик. При смене ТИПА у существующей статьи редактор предупреждает о занятом slug до сохранения.

**«Таблица из редактора пропадает на сайте»** — не должна: теги таблиц и code в allowlist санитайзера, стили есть на всех контентных страницах. Если пропала — проверьте, что не вставлены через «код»/iframe (их санитайзер режет сознательно).

## 7. Где показываются картинки (матрица отображения, актуально 2026-11-17)

### 7.1 Обложка статьи (cover, все типы: новость/событие/идея/аналитика/интересное/видео)

| Место | Как показывается |
|---|---|
| **Детальная страница статьи** | Хиро-блок во всю ширину под заголовком (после meta-строки, до тезиса/чипсов): `max-height 420px`, `object-cover`, скругление. **Битая картинка прячется сама** (`onError`), страница остаётся чистой |
| **Карточки в лентах** | `NewsCard` (новости) — картинка сверху карточки; `ArticleCard`/`IdeaCard` через `CoverThumb` (тип поверх градиента); `VideoCard` — превью 16:9 (кастомный thumb, иначе cover) с play-кнопкой |
| **Где именно** | главная (секции-карусели по типам и связям), страница типа `/novost` и т.п., `/lenta`, `/poisk`, страницы тренда/компании/сюжета (блоки связанных материалов), карусели «новости/события по идее», автоподгрузка «следующий материал» внизу статьи |
| **Превью репостов (og:image)** | бот-рендер API подставляет абсолютный URL обложки для Telegram/VK/соцсетей + `NewsArticle` JSON-LD `image` для поисковиков |

Картинки **внутри текста** (вставлены в TipTap) показываются в теле статьи/описании компании/лонгриде тренда: `max-width 100%`, скругление, санитайзер пропускает только безопасные теги. **Таблицы и code/pre** разрешены и оформлены на всех контентных страницах (рамки, фон шапки, скролл широких таблиц, подсветка кода).

### 7.2 Тренды (cover тренда)

| Место | Как |
|---|---|
| Главная, карусель «Тренды» | фоновая картинка в карточке 3:4 (название поверх, градиент снизу) + текстовая карточка-вступление |
| Превью репостов (og:image) | бот-рендер тренда |
| Детальная страница тренда | **обложка НЕ показывается** — только лонгрид (description) и список материалов |

### 7.3 Компании (logo; coverMediaId в БД есть, но веб не использует)

| Место | Как |
|---|---|
| Превью репостов | og:image = логотип + `Organization` JSON-LD `logo`/`image` |
| Детальная страница компании | **логотип и обложка НЕ показываются** — заголовок, oneLiner, описание (TipTap), тикеры/раунды, материалы о компании |

### 7.4 Сюжеты (coverMediaId в БД есть)

| Место | Как |
|---|---|
| Превью репостов | og:image = обложка сюжета (бот-рендер) |
| Детальная страница сюжета | **обложка НЕ показывается** — название, описание, хронология серий |

### 7.5 Обработка файлов (актуально для всех)

- **Автопережатие на входе:** любая загрузка (до 10 МБ) и ИИ-генерация прогоняются через sharp — до 1600 px по ширине + WebP q80 + strip метаданных. Типичный файл 100–500 КБ.
- **alt-текст** (переименование в медиатеке, ✎) — участвует в поиске по медиатеке и подставляется в alt при вставке из медиатеки в текст; на сайте в alt хиро/карточек уходит заголовок статьи/тренда.
- **Вставка в текст**: тулбар редактора — 📤 загрузка с компьютера, 🗂 выбор из медиатеки (модалка), 🖼 по URL.
- **Битые внешние ссылки** (сейчас ~270 обложек со старого WordPress): на детальной странице прячутся; в карточках лент пока видны как битые — лечится импортом wp-архива.
- **Права:** загрузка/генерация/удаление/переименование — admin/super_admin; файлы отдаются публично с `/uploads/*` (caddy → API).
